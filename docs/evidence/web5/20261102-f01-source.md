## 4. Storage, races and data classification

- [Draft](../../../src/infrastructure/drafts/indexedDbDraftRepository.ts) and [operation](../../../src/infrastructure/drafts/web4OperationRepository.ts) writes resolve on transaction.oncomplete, not request success. Blocked/open/versionchange/unexpected-close sets fatal state; late open closes. Abort/quota/CAS retains protection; corrupt records quarantined, not deleted.
- Native two-tab tests prove one atomic owner/first mutation per checkpoint. Loser retains raw input. Operation scan blocks ordinary write/delete even with tampered draft marker; rehash across awaits is followed by byte/CAS revalidation.
- [Layout v3](../../../src/app/workspace/layoutPersistenceV3.ts) and [layout admission](../../../src/app/workspace/workspaceLayouts.ts) scopes v3 by actor+epoch; actor-only v1/v2 never auto-import server IDs. Dockview stores layout only; move remove/add does not release document. Close-all/reset/restore/logout uses common admission.
- Rapid Enter/Tab, editor barrier, duplicate pending commands and raw dirty close protection have existing regressions. [Production runtime](../../../src/app/runtime/createProductionRuntime.tsx), auth and [production drafts](../../../src/app/runtime/productionDrafts.ts) dispose old scope; late status/inventory cannot affect new actor/database.
- IndexedDB contains sanitized user/business drafts, immutable requests and terminal metadata, still sensitive business data. No JWT/refresh cookie/password/authorization/capability/SQL credential is persisted. Snapshot allowlists/strict decoders exercise this boundary. Access JWT stays in localStorage with known XSS residual; refresh remains HttpOnly.
- Logout removes only admitted terminal/clean data after scope lock; dirty/UNKNOWN survives. Failed cleanup stays reported/retryable. Pagehide flush is best effort, not crash durability.
