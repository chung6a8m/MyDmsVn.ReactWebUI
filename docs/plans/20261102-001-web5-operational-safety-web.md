## 0. Product goals, exclusions and invariants

WEB4 delivered actor+epoch-scoped IndexedDB draft, immutable operation ID/frozen intent, protected readback and conservative UNKNOWN. Roadmap 05 adds browser-side **safe operator reconciliation**, conditional user-confirmed resend only after proven server fence, trustworthy full IIS staging and candidate-specific acceptance, without weakening local persistence/permissions/stock boundaries.

- Preserve React/TypeScript/Vite, default Tailwind CSS v4 + shadcn/ui Nova/Base UI (no Business Compact/font restyle), Zustand feature-owned stores, AG Grid Community, Dockview, Floating UI lookup, TanStack Query, OWIN/net48 HTTP host, existing production ports and actor/capability fences. No switch to framework/AG Grid Enterprise, no new module.
- Preserve WEB4 `web4-v1` canonical 48 corpus blobs (source backend `1c603c6ac57e59a3f7b4bc6ca976b2d531c079aa`), SHA/fingerprint, exact epoch+actor+generation+document identity, local draft raw/lookup/line identity and immutable prepared request. Sales repeated Product/gift allowed, Receipt Product unique, server moving-average inventory/COGS authoritative.
- **Never store access/refresh token, cookie, SQL credential, authorization/capabilities in IndexedDB**. Owner retains short JWT access token in localStorage (known XSS residual); refresh GUID remains HttpOnly cookie. Do not silently change auth/permission model.
- **No auto-retry:** status 404/403/timeout/expired, missing journal and OS crash are **not** rollback evidence. Never re-POST with new operation ID to “fix” UNKNOWN, never use public Get as protected settlement. Same-key user resend remains disabled by default until B01 proof + B02 compatibility/security review + F02 explicit UI acceptance; every action after negative tombstone must be new user intent and fresh baseline.
- Do not reopen WEB1–04 tasks or change legacy Web11/Desktop10 compatibility. Backend CEX remains independently active. Full IIS, production release, Telex/VNI/Narrator and operator tooling are NOT implicitly approved.

## 3. F02 — Terminal-resolution UX and conditional explicit resend (WEB5-02)
